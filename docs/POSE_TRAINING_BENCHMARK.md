# COCO 热力图课堂参考实验

这是一次真实浏览器WebGL训练的记录，不是为学生预载的权重或预设成绩。默认仍从随机卷积权重和本次训练标签先验开始。

固定配置：1024训练、40验证、40测试；种子42、输入128、输出32×32×17；81817个总参数；Adam 0.001、batch8、水平翻转、80轮。每轮检查验证点距，保留最佳第15轮；只在选择结束后评估测试集。

|集合|平均骨架点距|模型点距|平均骨架PCK|模型PCK|
|---|---:|---:|---:|---:|
|验证|14.54|12.55|65.9%|74.6%|
|测试|11.77|10.01|74.6%|81.8%|

点距是归一化欧氏距离×160的参考像素，PCK阈值为裁剪图宽度10%，不是COCO AP。基线只由这1024张训练图的标签计算。此次验证点距比基线低13.7%，测试点距低15.0%；结论仅适用于这份全身人物子集。

头面部改善更明显，手腕与复杂姿态仍不稳定。40张测试图数量较小，不能视为通用高精度或武术专用能力的证明。不同设备WebGL与浮点实现可能产生不同结果；学生需比较自己的模型与同一基线。

逐关节分数、数据/权重SHA256、验证检查点见同目录pose-heatmap-reference.json。实际实验权重与原始日志在本地outputs/pose-v2，未将它们自动加载给学生。参考实验仅用于验证方案和记录维护证据。
