# 描骨辨势 · 从零训练姿态模型

本实验已完整移植到行知实验室，位于“描骨辨势”的拓展区，排在“让代码，替你找到关节点。”之前，点击“进入从零训练实验”加载。也可独立打开 `/pose-training/index.html`。所有引擎、72张图片和标注均位于 `public/pose-training`，不依赖原独立站点。

嵌入时使用原站学生草稿标识隔离标注、模型权重和实验记录。切换到其他课时会在当前批次后暂停并自动保存，返回时保持当前实验。此实验的模型和报告在本机保存、导出；原有课堂提交功能保持原样。

面向一节45分钟课程的人体姿态估计教学系统。学生在浏览器中查看真实图片与人工标注，制作关键点标签，从随机权重训练一个小型CNN，再上传单人图片，得到17个二维关键点。没有使用预训练姿态模型，也没有预设的假训练曲线。

## 本地运行

随原网站启动或使用原网站 Windows 离线包，无需单独启动 PoseLab。训练引擎和图片随网页加载，运行不需要 Python 环境或外部模型服务。建议先用8张、5轮检查机房性能。

## 完整流程

1. **认识数据**：72张真实COCO图片，17点人工标注；每张原图只保留一个人物。48训练、12验证、12测试，按原始image_id分组。
2. **亲手标注**：点击放点、拖动修正，区分v=2可见、v=1遮挡但已标注、v=0未标注。上传照片后自动按比例留白为正方形，手工标至少6个点；可导入标准COCO17点JSON和对应图片。
3. **从零训练**：3层可训练卷积、64单元全连接、34坐标输出，约13.8万参数；每次从零训练使用随机初始化，不加载权重。所有卷积和输出层都通过Adam更新。
4. **检验模型**：对验证图、训练图或上传图预测，展示17点与骨架，导出JSON/PNG；独立测试集PCK和平均点误差仅在主动评估时计算。
5. **保存成果**：模型自动存入本机IndexedDB；可以导出包含权重的单文件模型并导入恢复。标注和报告暂存本机；清除网站数据或使用隐私模式可能导致丢失。模型恢复后继续训练会重新创建优化器。

## 教学安排（45分钟）

- 5分钟：对比行为分类与姿态估计，理解输入像素与输出坐标。
- 8分钟：查看人工标注，亲手修改肩、膝、踝等关键点。
- 15分钟：默认配置从零训练，观察训练/验证曲线和训练前后预测。
- 10分钟：用自己的照片验证，最后评估测试集并导出模型。
- 7分钟：改变样本数或学习率做对照实验，导出实验报告。

## 训练与评估的准确含义

- 输入64×64×3，归一化到0～1；课堂图片为160×160的人物裁剪图。
- 回归输出为17×2归一化坐标，sigmoid范围0～1，不输出置信度，也不进行多人目标检测。
- 损失为有效关键点坐标的masked MSE；v=0不参与训练和评估，v=1与v=2均参与。
- 翻转增强仅用于训练，图像水平翻转时同时交换左右关节点和可见性mask。
- 图表包含epoch 0真实误差；训练曲线使用每轮更新后的模型重新评估训练集，不是对批次损失的平滑动画。
- PCK@0.1定义为：预测关键点欧氏距离不超过图像宽度10%（160px图上16px）。它是本课堂采用的阈值，不等于COCO AP或所有论文中的PCK定义。
- 暂停发生在当前批次后；最后一轮如仅完成部分批次，报告中标明。
- 内置数据不足以训练高精度通用模型；新人物、背景、视角、遮挡会造成误差。不要把画出的完整骨架等同于预测正确。
- 导入数据按原图ID及文件名分组，避免同一原图的人物跨集合。若多张图片来自同一视频，仍应在课前按视频来源检查划分。
