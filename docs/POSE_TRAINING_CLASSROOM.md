# 描骨辨势 · COCO 热力图训练课堂

实验位于“这一次，亲手训练一个找点的模型。”，排在原 Python 找点实验之前。点击进入加载，或独立打开 `/pose-training/index.html`。所有图片、标签、TensorFlow.js 都随网站与离线包提供，上传图片不发到服务器。学生的标注、模型与报告按原站学生草稿标识隔离。

## 数据

- 1104张真实COCO图片，每张原图只选择一个人物，17点人工标注。
- 1024训练来自COCO train2017；40验证、40测试来自COCO val2017。原始image_id不重叠。
- 图片许可证仅取元数据license=4（CC BY 2.0）。逐图Flickr原作链接、许可证、image/annotation ID见assets/dataset.json，标注为COCO CC BY 4.0。
- 选择至少15个有标注关键点、肩髋膝踝完整、躯干向上、bbox高至少160且高宽比至少1.2的全身人物；用于常见全身姿态教学，非武术专用集或完整COCO基准。
- 人工bbox放大1.16倍成正方形，等比裁剪/填充至256像素。新照片由学生先框完整人物，采用相同规则。COCO导入仍读取人工bbox。
- 重建脚本：scripts/prepare-pose-training-v2.py。原始下载只在work目录，不随站点发布。

## 从零训练

输入128×128×3，像素除255。随机初始化的小型编码器/解码器CNN保留32像素空间分辨率，通过跳跃连接输出32×32×17 logits。每个有效关节的标签为归一化高斯热力图，sigma=1.25格；masked spatial cross-entropy仅监督v=1或2，v=0不参与。

仅从本次选中训练标签计算宽高斯位置先验，加在网络logits上，帮助小样本训练稳定。这是训练数据统计，并非外部预训练模型；界面、报告和模型导出均说明并保存该先验。网络卷积与BatchNorm参数由真实Adam反传更新。水平翻转图像时同时翻转热力图、交换左右通道与mask。最终坐标取每个关节空间softmax的期望。

默认种子42、1024张、学习率0.001、batch8、80轮，保留验证集平均点距最低的权重。各轮曲线保留真实测量，训练结束后的模型成绩对应所保留权重。先用8张5轮检查机房性能；完整配置用时取决于显卡/浏览器，不保证15分钟完成。可暂停、继续，继续时重建Adam优化器。离开课时会在当前批次后暂停并保存。

## 如何判断是否学会

界面比较同一验证集上的模型与“不看图片的固定平均骨架”。平均骨架只使用所选训练标签，不能读取验证/测试标签来拟合。损失下降不代表定位准确。

点距为归一化欧氏距离乘160的参考像素值，独立于显示尺寸；PCK@0.1是点距小于裁剪图宽10%的比例，不是COCO AP。验证集只用于选轮次，不更新参数。测试成绩仅在主动点击后计算，不用于选权重。不要反复以测试成绩调参。

## 保存与兼容

模型自动保存到本机IndexedDB；新版导出包含实际权重、训练标签先验、配置、曲线、数据签名、最佳轮次与初始预测。旧64像素坐标回归模型无法加载到新结构；旧存储和文件仍保留，新模型使用单独命名空间。数据/标签变化后禁止接着旧实验训练，需要从零开始。图片标注仍保存在原学生命名空间。

可导出模型JSON、17点JSON（上传图同时提供原图像素坐标）、骨架PNG、图片与COCO标签ZIP、实验Markdown报告。热力图只是相对响应，不是校准置信度。清理网站数据或隐私模式可能丢失本机实验，请及时导出。

## 教学边界

1104张全身图与小网络仍不能保证任意背景、多人、倒立、严重遮挡或新武术姿势的精确定位。完整骨架不代表全部关节正确。教师可将从零模型与下方成熟Python模型做真实对照；不能用成熟模型的输出冒充学生训练结果。
