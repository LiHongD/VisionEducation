# 行知实验室 · 离线免安装版

此版本在 Windows 10/11 64 位教师电脑运行。教师电脑连接校园局域网，学生电脑通过浏览器访问。正常教学无需互联网、ChatGPT 登录、Node.js 安装、Python 安装、npm 或命令行操作。

## 学校管理员首次准备一次

1. 将完整的“离线免安装版”文件夹拷贝/解压到教师电脑，例如桌面或 D 盘；不要在压缩包里直接运行。
2. 保留 `runtime`、`app` 和 `data` 文件夹，不要只复制启动脚本。
3. 教师电脑与学生机连接同一个可互通的校园局域网。由管理员允许随包 `runtime/node.exe` 的专用机房网络访问；默认端口 8787，占用时会自动选择 8788–8807。
4. 检查一台学生机能否打开教师端顶部显示的地址。若机房做了设备隔离或禁止脚本运行，请由管理员按校内规则完成一次配置。

不需要教师自行下载安装开发软件。运行环境和模型已随包提供。此包不修改防火墙或系统安全策略，也不连接在线课堂。

## 教师每次上课

1. 双击 **启动系统.vbs**，浏览器会自动打开教师工作台。如果学校禁用了 Windows 脚本宿主，双击 **启动系统.cmd**。
2. 创建课堂，得到 8 位课堂码。
3. 将顶部的“学生入口地址”和课堂码发给学生，或在投影上展示。学生填写姓名/学号加入，无需安装软件。
4. 学生完成学习后提交；教师可以查看答卷、点评、展示作品、下载分类模型和查看排名。
   “量势成规”的角度规则可独立提交：学生选择马步、弓步对应动作，点击“提交规则并检验”；教师在“角度规则自动检验”中查看正确率、混淆矩阵、逐样本结果和规则快照，具体设计见随包 `docs/角度规则评测设计.md`。
5. 下课后双击 **停止系统.cmd**，数据会保留。再次启动可以继续使用已有课堂。

重复双击启动会重新打开已运行的系统，不会重复开启另一套课堂。关闭浏览器不会停止服务。

教师登录按每套程序的 `data` 目录分别保存，不同端口的本地版本不会互相覆盖登录；同一版本服务重启后，浏览器原有教师会话仍可使用。教师入口统一为 `127.0.0.1`。更换浏览器、退出登录或移动程序目录后，请双击该程序自己的启动文件重新打开。

## 学生电脑

使用较新的 Chrome 或 Edge 浏览器，打开教师给出的 `http://教师电脑局域网地址:端口/classroom#classroom`。每位学生使用自己的电脑/浏览器身份，不要共用同一个浏览器会话。

3D 人物、描点、角度规则、Python、YOLO 识别、分类器训练与图片预测在学生机浏览器运行；模型和运行文件从教师电脑的局域网服务加载。答卷、正式分类模型评测和排名在教师电脑统一处理。

此版本为校园 HTTP 地址补充了 Pyodide 所需的 SHA-256 完整性校验，避免依赖安装 HTTPS 证书。第三方模型与 Python 运行资源仍使用随项目提供的固定文件。

## 数据与备份

- `data/classroom.sqlite`：班级、成员、答卷、点评与模型评测记录。
- `data/models/`：学生正式提交的分类模型文件。
- `data/backups/`：手动生成的完整数据备份。
- `data/logs/server.log`：本地服务日志。
- 学生未提交的草稿、规则和本机模型仍保存在学生自己的浏览器，可在对应页面导出。

双击 **备份数据.cmd**，或在教师端的“系统管理 / 数据备份”中生成备份。备份包含数据库快照和模型文件，不包含重复的教学素材。恢复时先停止系统，再将备份的 `classroom.sqlite` 和 `models` 放回 `data`；替换前保留当前数据副本。

升级程序时保留原有 `data` 文件夹。迁移会自动按版本应用，不需要手动执行 SQL。复制本包不会带来在线课堂已有的答卷和班级数据。

## 故障检查

| 情况 | 处理 |
| --- | --- |
| 双击后没有打开浏览器 | 尝试“启动系统.cmd”，检查 `data/启动错误.txt` 和日志 |
| 教师端可用，学生机打不开 | 核对机房网卡地址、局域网连通性、防火墙与设备隔离规则 |
| 提示需要教师登录，课堂读取失败 | 双击当前版本的“启动系统.vbs”恢复教师入口；不要使用另一个版本的启动文件。课堂数据仍保存在各自 data 目录 |
| 显示多个学生地址 | 选择机房网卡地址；网线/无线网络切换后在系统管理中刷新 |
| 学生机看到教师身份提示 | 教师管理入口只在教师电脑通过启动器开放，学生使用学生入口 |
| Python 首次运行需要等待 | 浏览器正在从教师电脑加载约 40 MB 模型和运行资源；可在上课前预热 |
| 需要换教师电脑 | 先停止服务，再复制完整程序文件夹，包括 `data`；在新电脑重新启动 |

`data/.teacher-session.json` 是本地教师会话文件，不要发给学生或公开分享；它不会随新生成的免安装包分发，也不会通过网站下载接口提供。学生局域网访问仍不能获得教师权限。

已验证 44 个学生身份通过本地 HTTP 服务同时加入、独立提交、读取答卷，模型收件与重启保留；实际 44 台机房电脑的浏览器性能及网络速度仍需在目标机房验收。

## 开发者重新打包

源码中的 `offline/` 提供独立的 Node HTTP 服务与本地 SQLite/文件存储适配器，复用原有课堂 API；不需要安装 Cloudflare、Wrangler 或整套前端依赖到教师电脑。

在开发电脑准备项目依赖后执行 `npm run build:offline`。打包器使用并校验 Node.js 24.14.1 官方 Windows x64 二进制，随包保留 Node 许可证、项目 AGPL-3.0 许可、第三方声明及可运行源码。输出目录和 ZIP 保存在项目上一级的 `output`。
