# 马步/弓步真实图片验证资料

正式候选清单见 `sources.json`：7 张马步、6 张弓步，来自 8 个来源站点。每张图片均真实下载并逐图人工检查，标签依据教学页的动作名称和人物下肢形态共同确定。没有把镜像、裁剪、不同文字标注或调色版计作新样本。

`source-images/` 是不公开的本地研究原图。`research/` 是不公开的网页/PDF及下载中间文件。`rejected-candidates.json` 记录剔除理由。应用公开资源应只包含关键点数值及来源索引，不应复制这些版权未开放的原图。

## 已检查事项

- 全身及双脚完整；臀、膝、踝没有明显遮挡；排除仆步、半马步、后腿严重重叠。
- 来源动作名明确；没有凭关键词检索结果直接当作正确标签。Body.Mind 页虽然写 horse stance，实际图片是仆步，已剔除。
- Wayland Li 与 Long Hui 的步型配图为教材线描，已剔除真人验证集。
- Maling 同一底图三个标注版本只保留一个。
- SHA-256 记录的是本地原始图片字节；SportSG 图为 PDF 第 7 页直接解出的原嵌入 JPEG，没有重新截图压缩。

## 提取关键点前的注意

1. Maling 的 PNG 有透明背景，模型预处理应合成白色或中性背景，避免透明像素默认变成黑色。不要移除版权水印。
2. `shaolinusa-1` 只有 199 × 200 像素，实际提取后腿关键点明显错误，已从正式集合剔除，完整记录留在 `sources.json` 的 `exclusions` 中。替换为 UCL 博士论文第 26 页明确标签的清晰真人弓步照片。不能人工造点来提升成绩。
3. Sarah Chang 两张是高跟鞋风格化武术照片，可用于动作类别识别；不能当作学校体育穿着规范或安全示范。
4. `dragons-2` 为背面马步，左右关键点语义依 COCO 人体左右定义；弓步应允许左/右前腿，避免只匹配画面某一侧。
5. 图片只是小规模固定教学验证集，含不同视角及服装，不能据此声称真实课堂泛化准确率，更不能把动作分类正确率解释为体育动作达标率。
